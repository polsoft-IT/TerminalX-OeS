# anim - Animation Commands

## NAME

anim - Animation commands (matrix, fire, wave, spin, pulse, list, stop, stats)

## DESCRIPTION

The anim command provides access to TerminalX's animation engine. Display various terminal animations including matrix rain, fire effects, and more with 18 available commands.

## SYNOPSIS

```
anim matrix
anim fire
anim wave
anim spin
anim pulse
anim list
anim stop
anim stats
anim snow
anim rain
anim stars
anim confetti
anim speed <fps>
anim color <color>
```

## OPTIONS

- `matrix` - Display matrix rain animation
- `fire` - Display fire animation
- `wave` - Display wave animation
- `spin` - Display spinning animation
- `pulse` - Display pulse animation
- `list` - List available animations
- `stop` - Stop current animation
- `stats` - Show animation engine statistics

## EXAMPLES

```
anim matrix
anim fire
anim wave
anim list
anim stop
```
