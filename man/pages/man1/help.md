# help - Help System v1.1.0

## NAME

help - Help system for TerminalX commands and documentation

## DESCRIPTION

The help command provides quick access to command help, usage information, and documentation for TerminalX. It serves as a fast reference guide for available commands and their basic usage.

## SYNOPSIS

```
help [command]
help list
help categories
help search <pattern>
```

## OPTIONS

- `[command]` - Show help for specific command
- `list` - List all available commands
- `categories` - List command categories
- `search <pattern>` - Search for commands matching pattern

## EXAMPLES

```
help
help geo
help list
help categories
help search wifi
```
