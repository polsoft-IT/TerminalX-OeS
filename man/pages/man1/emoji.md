# emoji - Emoji Commands

## NAME

emoji - Emoji commands (all, cat, find, page, random, stats)

## DESCRIPTION

The emoji command provides access to TerminalX's emoji library. Browse, search, and use emojis in your terminal with 17 available commands.

## SYNOPSIS

```
emoji all
emoji cat <category>
emoji find <name>
emoji page <number>
emoji random
emoji stats
emoji list
emoji categories
emoji search <query>
emoji favorite add <emoji>
emoji favorite remove <emoji>
emoji favorite list
emoji recent
```

## OPTIONS

- `all` - Display all available emojis
- `cat <category>` - Display emojis by category
- `find <name>` - Find emojis by name
- `page <number>` - Display emojis on a specific page
- `random` - Display a random emoji
- `stats` - Show emoji library statistics
- `list` - List emoji categories

## EXAMPLES

```
emoji all
emoji cat animals
emoji find smile
emoji random
emoji stats
```
