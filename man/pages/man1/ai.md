# ai - TerminalX AI Commands

## NAME

ai - AI commands (process, analyze, clear, context, status)

## DESCRIPTION

The ai command provides access to TerminalX's artificial intelligence capabilities including text processing, analysis, and context management.

## SYNOPSIS

```
ai process <text>
ai analyze <text>
ai clear
ai context
ai status
```

## OPTIONS

- `process <text>` - Process text with AI
- `analyze <text>` - Analyze text with AI
- `clear` - Clear AI context
- `context` - Show AI context
- `status` - Show AI status

## EXAMPLES

```
ai process "Hello, how are you?"
ai analyze "The system is running smoothly"
ai clear
ai context
ai status
```
