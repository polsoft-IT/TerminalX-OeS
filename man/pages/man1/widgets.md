# widgets - GUI Widgets Commands

## NAME

widgets - GUI widgets commands (list, stats)

## DESCRIPTION

The widgets command provides access to TerminalX's GUI widget library. List available widgets and get widget statistics with 4 available commands.

## SYNOPSIS

```
widgets list
widgets stats
widgets info <widget>
widgets available
```

## OPTIONS

- `list` - List all available widgets
- `stats` - Show widget library statistics
- `info <widget>` - Get detailed widget information
- `available` - Show available widget types

## EXAMPLES

```
widgets list
widgets stats
widgets info button
```
