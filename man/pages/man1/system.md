# system - System Commands

## NAME

system - System commands (sysinfo, processes, kill, storage, time, and more)

## DESCRIPTION

The system command provides comprehensive system information and management capabilities. View system details, manage processes, check storage, monitor hardware, and perform various system operations with 22 available commands.

## SYNOPSIS

```
system sysinfo
system processes
system kill <pid>
system storage
system time
system uptime
system hostname
system platform
system environment
system cpu
system memory
system disk
system network
system users
system services
system load
system temperature
system power
```

## OPTIONS

- `sysinfo` - Display detailed system information
- `processes` - List all running processes
- `kill <pid>` - Terminate a process by PID
- `storage` - Show storage usage statistics
- `time` - Display current system time
- `uptime` - Show system uptime
- `hostname` - Display system hostname
- `platform` - Display platform information
- `environment` - Display environment variables
- `cpu` - Display CPU information and usage
- `memory` - Display memory usage statistics
- `disk` - Display disk usage and performance
- `network` - Display network information
- `users` - Display logged-in users
- `services` - Display system services status
- `load` - Display system load averages
- `temperature` - Display system temperature
- `power` - Display power management information
